# Dreo Arcana

A game system for [Foundry Virtual Tabletop](https://foundryvtt.com/).

## Installation

Clone this repository into your Foundry `Data/systems` folder:

```
Data/systems/dreoarcana
```

The folder name must match the system `id` (`dreoarcana`).

## Structure

| Path | Purpose |
| --- | --- |
| `system.json` | System manifest |
| `module/` | System scripts and data models |
| `lang/` | Localization files |
| `styles/` | Stylesheets |

## Compatibility

Foundry VTT v12 – v13.
